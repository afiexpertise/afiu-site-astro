# Résumé

Faire réaliser par Vibe Code une modification concrète d'un projet à partir d'un besoin issu du fil rouge.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Mistral Vibe / Vibe Code
- **Ordre :** 7
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-450 — Utiliser le raisonnement guidé**
- **IA-460 — Utiliser les contraintes**
- **IA-510 — Collaborer avec l’IA**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Exprimer un besoin technique à partir du besoin métier.
2. Faire comprendre le dépôt avant modification.
3. Valider un plan.
4. Faire modifier et tester le code.
5. Revoir le résultat.

# Agenda — théorie

- Contexte de projet et codebase.
- Planification de la modification.
- Outils et environnement d'exécution.
- Tests, débogage et itération.
- Revue et sécurité.

# Fil rouge — expérimentation personnelle

**État entrant :** Une étape de la tâche nécessite désormais un outil ou une modification logicielle.

1. Décrire la fonctionnalité et les critères de succès.
2. Faire explorer le projet.
3. Demander un plan avant écriture.
4. Faire réaliser la modification et exécuter les tests.
5. Inspecter le résultat et corriger les écarts.

**État sortant :** Une modification testée répond à un besoin réel du fil rouge.

# Réflexion et questions de groupe

- **La qualité dépend-elle plus du modèle ou du contexte fourni?**
- **Comment reconnaître une solution surdimensionnée?**
- **Quels tests doivent être exigés?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
