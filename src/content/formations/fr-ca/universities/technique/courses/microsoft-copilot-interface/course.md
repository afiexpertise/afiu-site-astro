# Résumé

Transposer les compétences du tronc commun dans Microsoft Copilot et configurer l'interface comme espace de travail d'une tâche.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Microsoft Copilot
- **Ordre :** 3
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-230 — Adapter une requête à un contexte**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-610 — Protéger les données**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Lire l'interface et ses espaces de conversation.
2. Configurer paramètres, modes et personnalisation.
3. Utiliser fichiers, recherche et modalités disponibles.
4. Comprendre les accès et permissions mobilisés.
5. Réaliser une première tâche complète dans Copilot.

# Agenda — théorie

- Interface, historique et nouvelle conversation.
- Paramètres, modes et personnalisation.
- Fichiers, recherche, texte et voix selon disponibilité.
- Sources, identité et permissions.
- Validation et fermeture de la tâche.

# Fil rouge — expérimentation personnelle

**État entrant :** Le participant maîtrise M0 à M2 et doit appliquer ces compétences dans Microsoft Copilot.

1. Configurer Copilot pour le travail demandé.
2. Créer la conversation du fil rouge et fournir le courriel.
3. Ajouter les sources disponibles.
4. Produire une première réponse puis vérifier les faits et contraintes.
5. Valider le résultat et documenter ce qui manque pour la suite.

**État sortant :** La tâche est correctement installée dans Copilot avec un premier résultat vérifié.

# Réflexion et questions de groupe

- **Qu'est-ce qui change réellement par rapport à M1/M2?**
- **Quels réglages doivent être persistants?**
- **Quels accès sont nécessaires à cette tâche?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
