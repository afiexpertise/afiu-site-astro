# Résumé

Passer d'une conversation temporaire à un contexte de travail persistant pour une famille de tâches similaires.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Objectifs pédagogiques

1. Reconnaître quand une conversation ne suffit plus.
2. Organiser directives, sources et contexte réutilisable.
3. Choisir entre Pages, Loop et Bloc-notes selon le besoin.
4. Éviter de figer des informations obsolètes.
5. Maintenir une validation humaine.

# Agenda — théorie

- Conversation temporaire vs contexte persistant.
- Pages, Loop et Bloc-notes : rôles respectifs.
- Sources, directives et contexte réutilisable.
- Espace individuel et espace collectif.
- Maintenance et obsolescence.

# Fil rouge — expérimentation personnelle

**État entrant :** La tâche est terminée mais plusieurs demandes similaires sont attendues.

1. Identifier ce qui peut être réutilisé du fil rouge.
2. Créer un espace de travail persistant adapté.
3. Ajouter les sources stables et retirer les éléments purement circonstanciels.
4. Formaliser les directives réutilisables.
5. Tester une nouvelle demande similaire sans reconstruire tout le contexte.

**État sortant :** Un contexte réutilisable accélère les tâches futures sans transformer le contenu circonstanciel en vérité permanente.

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
