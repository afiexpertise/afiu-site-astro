# Résumé

Déléguer une tâche multi-étapes à Claude/Cowork en définissant les limites, les points de décision et les critères de réussite.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Anthropic Claude
- **Ordre :** 7
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-460 — Utiliser les contraintes**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-610 — Protéger les données**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Identifier une tâche adaptée à une exécution agentique.
2. Définir le résultat et les contraintes.
3. Superviser le plan proposé.
4. Gérer les validations et accès.
5. Évaluer le résultat avant clôture.

# Agenda — théorie

- Conversation vs exécution agentique.
- Planification et environnement de travail.
- Outils, fichiers et accès.
- Points d'arrêt et décisions humaines.
- Validation et responsabilité.

# Fil rouge — expérimentation personnelle

**État entrant :** Le contexte et les sources sont suffisamment structurés pour déléguer une nouvelle occurrence de la tâche.

1. Formuler la tâche complète avec ses critères de succès.
2. Faire établir puis revoir le plan.
3. Laisser Claude/Cowork exécuter plusieurs étapes.
4. Intervenir aux décisions importantes.
5. Inspecter les livrables et décider si la tâche est réellement terminée.

**État sortant :** Une tâche complexe a été déléguée sous supervision humaine explicite.

# Réflexion et questions de groupe

- **Le meilleur assistant doit-il nous poser plus ou moins de questions?**
- **Quelles décisions ne doivent jamais être implicites?**
- **Quand reprendre la main?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
