# Apprendre à dialoguer avec l’intelligence artificielle

## Description

Cette formation présente les fondements du dialogue avec l’intelligence artificielle générative.

## Objectifs

- Concevoir des requêtes efficaces.
- Comprendre les meilleures pratiques.
- Augmenter la pertinence des réponses générées.
- Utiliser l’IA dans un contexte professionnel.
- Respecter les exigences de sécurité et de gouvernance.
