# Résumé

Organiser dans Projects le contexte, les instructions et les sources d'une famille de tâches similaires.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** OpenAI ChatGPT
- **Ordre :** 5
- **Durée :** 210 minutes

- **IA-230 — Adapter une requête à un contexte**

# Objectifs pédagogiques

1. Distinguer conversation et Project.
2. Choisir la bonne granularité d'un Project.
3. Organiser instructions et sources réutilisables.
4. Éviter de rendre persistantes des informations circonstancielles.
5. Reprendre une nouvelle tâche sans reconstruire tout le contexte.

# Agenda — théorie

- Conversation vs Project.
- Instructions et sources du projet.
- Organisation des conversations.
- Contexte durable et frontières du projet.
- Maintenance, confidentialité et obsolescence.

# Fil rouge — expérimentation personnelle

**État entrant :** Une première tâche est terminée et des demandes proches vont revenir.

1. Identifier ce qui est stable dans le fil rouge.
2. Créer un Project adapté à cette famille de tâches.
3. Ajouter instructions et sources de référence.
4. Retirer les éléments qui ne concernent qu'une occurrence.
5. Démarrer une nouvelle demande similaire et mesurer le contexte déjà disponible.

**État sortant :** Le contexte réutilisable est organisé dans un Project sans confondre mémoire de travail et vérité permanente.

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
