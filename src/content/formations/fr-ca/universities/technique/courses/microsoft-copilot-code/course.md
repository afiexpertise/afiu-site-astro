# Résumé

Transformer un besoin issu de la tâche en petite solution logicielle, puis tester et vérifier ce qui a été généré.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Microsoft Copilot
- **Ordre :** 6
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-450 — Utiliser le raisonnement guidé**

- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Transformer un besoin fonctionnel en objectif de solution.
2. Fournir un contexte technique exploitable.
3. Faire planifier une implémentation.
4. Tester et corriger le résultat.
5. Évaluer les risques du code généré.

# Agenda — théorie

- Du besoin métier au besoin fonctionnel.
- Contexte de développement et contraintes.
- Planification avant modification.
- Tests, erreurs et itération.
- Sécurité, revue et responsabilité du code.

# Fil rouge — expérimentation personnelle

**État entrant :** Une étape récurrente du fil rouge gagnerait à être prise en charge par un petit outil.

1. Décrire précisément le besoin issu de la tâche.
2. Faire proposer une solution minimale.
3. Construire ou modifier la solution.
4. Exécuter les tests et provoquer au moins un cas d'erreur.
5. Revoir le résultat avant de l'utiliser sur le fil rouge.

**État sortant :** Une petite solution testée prend en charge une étape répétitive de la tâche.

# Réflexion et questions de groupe

- **Quand construire est-il préférable à converser?**
- **Qui est responsable du code produit?**
- **Quel niveau de test est suffisant avant usage?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
