# Résumé

Comprendre l'interface de Microsoft 365 Copilot, son contexte organisationnel, les sources mobilisées et l'effet des permissions sur la tâche.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Microsoft 365 Copilot
- **Ordre :** 3
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-230 — Adapter une requête à un contexte**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-610 — Protéger les données**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Se repérer dans Microsoft 365 Copilot.
2. Comprendre le rôle du contexte de travail et des sources organisationnelles.
3. Distinguer Web, fichiers et données accessibles par l'utilisateur.
4. Vérifier permissions et provenance.
5. Réaliser une première tâche complète.

# Agenda — théorie

- Interface et conversations.
- Work IQ et contexte de travail.
- Web, Microsoft 365 et sources organisationnelles.
- Identité, permissions et sécurité.
- Validation, citations et limites.

# Fil rouge — expérimentation personnelle

**État entrant :** Le participant maîtrise la conversation et doit désormais l'appliquer à son environnement de travail Microsoft 365.

1. Ouvrir la tâche à partir du courriel.
2. Demander à Copilot de reconstituer le contexte disponible.
3. Inspecter les sources utilisées.
4. Identifier ce qui manque et ce qui est inaccessible.
5. Préparer un plan de travail et une première réponse vérifiée.

**État sortant :** La tâche est contextualisée avec les informations organisationnelles réellement accessibles au participant.

# Réflexion et questions de groupe

- **Copilot « sait-il » une information ou peut-il simplement y accéder?**
- **Que révèlent les permissions existantes sur notre gouvernance documentaire?**
- **Quelles sources doivent avoir priorité?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
