# Résumé

Compléter une tâche par la recherche et des sources connectées tout en maîtrisant provenance, permissions et actions.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** OpenAI ChatGPT
- **Ordre :** 6
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-610 — Protéger les données**

# Objectifs pédagogiques

1. Choisir entre recherche Web et source connectée.
2. Évaluer la pertinence d'une nouvelle connexion.
3. Comprendre autorisation et permissions.
4. Tracer la provenance des informations.
5. Contrôler les actions rendues possibles par un plugin.

- Provenance et validation multi-source.

# Fil rouge — expérimentation personnelle

**État entrant :** Le dossier contient encore des informations manquantes qui ne se trouvent pas dans les fichiers déjà fournis.

1. Identifier une question nécessitant une recherche externe.
2. Rechercher et comparer plusieurs sources.
3. Connecter une source pertinente lorsque disponible.
4. Utiliser uniquement les permissions nécessaires.
5. Produire une réponse sourcée puis vérifier l'origine de chaque information importante.

**État sortant :** Le participant sait enrichir une tâche avec des sources externes ou connectées sans perdre la maîtrise des accès.

# Réflexion et questions de groupe

- **Quand une nouvelle connexion améliore-t-elle vraiment la tâche?**
- **Quels risques introduit une capacité d'action?**
- **Faut-il privilégier une source interne ou externe lorsqu'elles divergent?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
