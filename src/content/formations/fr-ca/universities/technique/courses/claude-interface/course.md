# Résumé

Transposer les compétences du tronc commun dans Claude et configurer l'interface pour conduire une tâche complète.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Anthropic Claude
- **Ordre :** 3
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-230 — Adapter une requête à un contexte**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-610 — Protéger les données**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Se repérer dans l'interface et les conversations.
2. Configurer paramètres, styles ou instructions disponibles.
3. Ajouter fichiers et sources.
4. Comprendre les connexions et permissions.
5. Réaliser une première tâche complète.

# Agenda — théorie

- Interface et conversations.
- Paramètres, modèles, styles et personnalisation.
- Fichiers et modalités d'interaction.
- Recherche, connexions et permissions.
- Validation et limites.

# Fil rouge — expérimentation personnelle

**État entrant :** Le participant maîtrise M0 à M2 et doit appliquer ces compétences dans Claude.

1. Créer la conversation du fil rouge.
2. Fournir le courriel et configurer le contexte.
3. Ajouter les premières sources.
4. Produire une réponse puis demander une critique du résultat.
5. Vérifier les faits et conserver uniquement la version validée.

**État sortant :** La tâche est correctement installée dans Claude et son premier résultat est vérifié.

# Réflexion et questions de groupe

- **Qu'est-ce qui change sans changer les principes de M1/M2?**
- **Quelles préférences doivent persister?**
- **Quels accès sont nécessaires?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.

Modules 0 à 2 ou connaissances équivalentes.
