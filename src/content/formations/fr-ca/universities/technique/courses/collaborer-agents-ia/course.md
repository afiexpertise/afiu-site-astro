# Résumé

Ce cours introduit les agents comme niveau supplémentaire de délégation d'une tâche. Il apprend d'abord à utiliser et superviser un agent, puis à comprendre les principes de création d'un agent simple lorsque la conversation ou l'espace de travail persistant ne suffisent plus.

# Objectifs pédagogiques

1. Distinguer assistant conversationnel, projet, Bloc-notes, agent et automatisation de processus.
2. Reconnaître les tâches qui peuvent être partiellement déléguées à un agent.
3. Définir objectif, directives, connaissances, outils, permissions et critères de validation d'un agent.
4. Utiliser un agent existant en conservant une supervision humaine appropriée.
5. Tester et évaluer le résultat produit par un agent.
6. Comprendre les principes de création d'un agent simple dans les plateformes disponibles.
7. Identifier le moment où le besoin dépasse la tâche individuelle et relève plutôt d'un processus organisationnel ou d'une orchestration.

# Fil rouge

Le collaborateur observe qu'une partie de ses tâches est suffisamment définie et répétable pour être déléguée. Il apprend à le faire sans confondre délégation d'une tâche et automatisation complète d'un processus d'organisation.

# Compétences travaillées

- IA-130 — Comprendre le fonctionnement général d'un orchestrateur IA.
- IA-240 — Identifier objectif, contexte, attentes et sources.
- IA-320 — Évaluer la qualité d'une réponse.
- IA-420 — Utiliser le Context Engineering.
- IA-460 — Utiliser les contraintes.
- IA-510 — Collaborer avec l'IA.
- IA-530 — Utiliser l'IA dans les tâches quotidiennes.
- IA-610 — Protéger les données.
- IA-620 — Gérer les risques associés à l'IA.
- IA-630 — Appliquer un cadre de gouvernance IA.

# Préalables

Maîtriser les principes des modules 1 à 4 ou posséder une expérience équivalente.
