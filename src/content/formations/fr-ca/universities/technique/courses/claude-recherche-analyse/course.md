# Résumé

Mener une recherche multi-source, confronter des informations et documenter l'incertitude avant de produire une recommandation.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Anthropic Claude
- **Ordre :** 6
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-330 — Détecter les biais**
- **IA-340 — Réduire les ambiguïtés**
- **IA-420 — Utiliser le Context Engineering**
- **IA-450 — Utiliser le raisonnement guidé**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**

# Objectifs pédagogiques

1. Formuler une question de recherche précise.
2. Comparer plusieurs sources.
3. Repérer contradictions et biais.
4. Documenter les incertitudes.
5. Produire une recommandation qui distingue faits et interprétation.

# Agenda — théorie

- Question de recherche et périmètre.
- Recherche et synthèse multi-source.
- Contradiction, biais et qualité de source.
- Incertitude et limites.
- Faits, interprétation et recommandation.

# Fil rouge — expérimentation personnelle

**État entrant :** Un point ambigu du courriel nécessite une investigation plus approfondie.

1. Formuler la question de recherche issue de la tâche.
2. Rassembler plusieurs sources.
3. Faire identifier convergences et contradictions.
4. Vérifier manuellement les points critiques.
5. Produire une recommandation argumentée avec incertitudes explicites.

**État sortant :** La tâche dispose d'une analyse sourcée qui ne masque pas les contradictions ou l'incertitude.

# Réflexion et questions de groupe

- **Que faire lorsque deux sources crédibles se contredisent?**
- **Quand faut-il suspendre la conclusion?**
- **Comment présenter l'incertitude sans rendre le résultat inutilisable?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
