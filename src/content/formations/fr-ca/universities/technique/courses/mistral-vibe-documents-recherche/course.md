# Résumé

Analyser documents et recherches afin de construire une synthèse utile sans masquer contradictions ni limites.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Mistral Vibe
- **Ordre :** 4
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-330 — Détecter les biais**
- **IA-340 — Réduire les ambiguïtés**
- **IA-420 — Utiliser le Context Engineering**
- **IA-450 — Utiliser le raisonnement guidé**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**

# Objectifs pédagogiques

1. Analyser plusieurs documents.
2. Mener une recherche complémentaire.
3. Repérer contradictions et informations manquantes.
4. Distinguer synthèse et simplification.
5. Produire une réponse sourcée et vérifiée.

# Agenda — théorie

- Documents comme sources.
- Recherche complémentaire.
- Comparaison, contradiction et biais.
- Analyse et raisonnement guidé.
- Synthèse, provenance et validation.

# Fil rouge — expérimentation personnelle

**État entrant :** Le courriel nécessite un dossier plus complet que les informations initiales.

1. Ajouter les documents du fil rouge.
2. Extraire les faits utiles.
3. Rechercher les informations manquantes.
4. Confronter les différentes sources.
5. Produire une synthèse puis vérifier les passages critiques.

**État sortant :** Le participant dispose d'un contexte consolidé et de limites explicitement documentées.

# Réflexion et questions de groupe

- **Comment distinguer synthèse utile et simplification excessive?**
- **Quand une contradiction doit-elle bloquer la tâche?**
- **Que faut-il citer ou conserver comme preuve?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
