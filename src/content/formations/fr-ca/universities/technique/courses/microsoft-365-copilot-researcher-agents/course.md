# Résumé

Utiliser Researcher et des agents spécialisés pour déléguer une recherche ou une sous-tâche bien définie tout en vérifiant le résultat.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Microsoft 365 Copilot
- **Ordre :** 9
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-450 — Utiliser le raisonnement guidé**
- **IA-460 — Utiliser les contraintes**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Choisir entre conversation, recherche approfondie et agent.
2. Définir le mandat d'un agent.
3. Limiter les connaissances et outils nécessaires.
4. Évaluer le résultat produit.
5. Identifier quand le besoin relève plutôt d'un processus organisationnel.

# Agenda — théorie

- Recherche approfondie et synthèse multi-source.
- Agent spécialisé : objectif, instructions, connaissances et outils.
- Permissions et limites d'action.
- Évaluation et critères de réussite.
- Frontière entre tâche individuelle et processus.

# Fil rouge — expérimentation personnelle

**État entrant :** Une question complexe ou répétitive de la tâche justifie un niveau de délégation supérieur.

1. Formuler une question de recherche issue du fil rouge.
2. La confier à Researcher et vérifier les sources.
3. Définir un agent spécialisé pour une sous-tâche récurrente.
4. Tester l'agent sur une nouvelle occurrence.
5. Comparer le résultat à la méthode manuelle et documenter les limites.

**État sortant :** Le participant sait choisir et superviser un mécanisme de recherche ou de délégation spécialisé.

# Réflexion et questions de groupe

- **Quel travail gagne réellement à être délégué?**
- **Quand un agent devient-il trop spécialisé?**
- **À quel moment quitte-t-on la tâche individuelle pour entrer dans le processus?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
