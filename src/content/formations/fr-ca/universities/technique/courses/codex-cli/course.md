# Résumé

Poursuivre une tâche de développement dans le terminal avec Codex CLI en contrôlant contexte local, commandes et permissions.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** OpenAI ChatGPT / Codex
- **Ordre :** 9
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-460 — Utiliser les contraintes**
- **IA-510 — Collaborer avec l’IA**
- **IA-610 — Protéger les données**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Démarrer dans le bon dépôt et le bon répertoire.
2. Contrôler l'accès aux fichiers et commandes.
3. Faire planifier avant modification.
4. Exécuter tests et inspections.
5. Reprendre une session et valider un diff.

# Agenda — théorie

- CLI et contexte local.
- Permissions et approbations.
- Git, fichiers et shell.
- Agents, planification et reprise de session.
- Tests, diff et validation.

# Fil rouge — expérimentation personnelle

**État entrant :** La fonctionnalité précédente doit être corrigée ou maintenue directement dans l'environnement local.

1. Ouvrir Codex CLI dans le dépôt.
2. Faire diagnostiquer un problème sans modifier les fichiers.
3. Valider le plan proposé.
4. Autoriser une modification ciblée et lancer les tests.
5. Inspecter le diff, corriger si nécessaire et finaliser.

**État sortant :** Le participant sait réaliser une tâche technique locale avec Codex CLI sans abandonner le contrôle des opérations.

# Réflexion et questions de groupe

- **Quel niveau d'accès local est acceptable?**
- **Quelles opérations doivent nécessiter une approbation?**
- **Comment tracer et revoir le travail de l'agent?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
