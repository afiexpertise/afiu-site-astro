# Résumé

Piloter Claude Code depuis le terminal en maîtrisant sessions, permissions, fichiers, shell, Git et MCP.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Anthropic Claude / Claude Code
- **Ordre :** 9
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-460 — Utiliser les contraintes**
- **IA-510 — Collaborer avec l’IA**
- **IA-610 — Protéger les données**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Démarrer et reprendre une session CLI.
2. Contrôler les permissions accordées.
3. Utiliser fichiers, shell et Git de façon supervisée.
4. Mobiliser MCP lorsque pertinent.
5. Inspecter tests et diff avant validation.

# Agenda — théorie

- Sessions et reprise de contexte.
- Permissions et modes d'approbation.
- Fichiers, shell et Git.
- MCP et outils externes.
- Tests, diff et fermeture de session.

# Fil rouge — expérimentation personnelle

**État entrant :** La solution doit être maintenue ou corrigée directement dans l'environnement local.

1. Ouvrir Claude Code CLI dans le projet.
2. Faire diagnostiquer un problème sans écrire.
3. Valider un plan limité.
4. Autoriser les modifications et commandes nécessaires.
5. Vérifier tests et diff puis finaliser ou annuler.

**État sortant :** Le participant maîtrise une tâche de développement locale sans céder un accès non contrôlé à l'agent.

# Réflexion et questions de groupe

- **Comment équilibrer vitesse et contrôle?**
- **Quels outils externes sont acceptables via MCP?**
- **Quelles actions doivent toujours être réversibles?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
