# Résumé

Rassembler des sources, analyser des fichiers et construire un dossier factuel vérifiable avant de répondre à la demande.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Microsoft Copilot
- **Ordre :** 4
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-610 — Protéger les données**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Distinguer recherche et génération.
2. Sélectionner des sources pertinentes.
3. Analyser et comparer plusieurs fichiers.
4. Tracer les faits jusqu'à leur source.
5. Valider une synthèse avant de l'utiliser.

# Agenda — théorie

- Recherche vs génération.
- Sources primaires et secondaires.
- Analyse et comparaison de fichiers.
- Citations, provenance et contextualisation.
- Validation et gestion de l'incertitude.

# Fil rouge — expérimentation personnelle

**État entrant :** Le courriel est compris mais plusieurs informations nécessaires manquent.

1. Identifier les informations manquantes.
2. Rechercher les sources utiles.
3. Ajouter et analyser les fichiers reçus.
4. Comparer les informations et relever les contradictions.
5. Produire un dossier factuel sourcé utilisable pour la réponse.

**État sortant :** Le participant dispose d'un contexte factuel consolidé et vérifié.

# Réflexion et questions de groupe

- **Une réponse sourcée est-elle forcément correcte?**
- **Quand avons-nous suffisamment d'information pour poursuivre?**
- **Comment traiter une source contradictoire?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
