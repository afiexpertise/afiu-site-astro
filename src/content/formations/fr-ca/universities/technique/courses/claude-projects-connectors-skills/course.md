# Résumé

Structurer un contexte durable avec Projects, Connectors et Skills pour des tâches récurrentes sans confondre contexte, capacité et source.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Anthropic Claude
- **Ordre :** 5
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-230 — Adapter une requête à un contexte**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-610 — Protéger les données**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Créer un Project à la bonne granularité.
2. Organiser connaissances et instructions.
3. Comprendre le rôle des Connectors.
4. Formaliser une Skill réutilisable.
5. Contrôler permissions et obsolescence.

# Agenda — théorie

- Projects et contexte durable.
- Connectors : accès à des sources externes.
- Skills : capacité réutilisable.
- Permissions et moindre privilège.
- Maintenance du contexte et obsolescence.

# Fil rouge — expérimentation personnelle

**État entrant :** Une première tâche est terminée et des tâches similaires vont réutiliser une partie du contexte et de la méthode.

1. Créer le Project du fil rouge.
2. Ajouter les sources stables et instructions durables.
3. Connecter uniquement une source nécessaire.
4. Formaliser une Skill pour une étape répétitive.
5. Tester la Skill sur une nouvelle occurrence et vérifier ce qui a été réutilisé.

**État sortant :** Le participant dispose d'un environnement réutilisable où contexte, source et capacité sont clairement séparés.

# Réflexion et questions de groupe

- **Qu'est-ce qui relève du contexte, d'une Skill ou d'un Connector?**
- **Quelle permission est vraiment nécessaire?**
- **Comment maintenir un Project dans le temps?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
