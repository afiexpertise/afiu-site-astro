# Résumé

Prolonger le travail de code dans le terminal avec GitHub Copilot CLI en contrôlant le contexte local, les commandes et les permissions.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Microsoft Copilot / GitHub Copilot
- **Ordre :** 8
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-460 — Utiliser les contraintes**
- **IA-510 — Collaborer avec l’IA**
- **IA-610 — Protéger les données**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Démarrer une session CLI dans le bon contexte.
2. Faire inspecter un projet avant modification.
3. Demander un plan et limiter les permissions.
4. Exécuter tests et commandes de façon contrôlée.
5. Inspecter les changements avant validation.

# Agenda — théorie

- CLI, répertoire courant et contexte.
- Planification et exécution.
- Accès fichiers, shell et Git.
- Permissions et approbations.
- Tests, diff et reprise de session.

# Fil rouge — expérimentation personnelle

**État entrant :** La solution créée précédemment doit être reprise directement dans son environnement local.

1. Ouvrir le CLI dans le projet du fil rouge.
2. Faire expliquer l'état du projet sans modification.
3. Demander une correction ou amélioration ciblée.
4. Lancer les tests et inspecter le diff.
5. Valider ou annuler les changements selon le résultat.

**État sortant :** Le participant sait accomplir une petite tâche technique depuis le terminal sans abandonner le contrôle des actions.

# Réflexion et questions de groupe

- **Qu'apporte réellement le CLI?**
- **Quelles commandes doivent être interdites ou soumises à approbation?**
- **Comment conserver une trace du travail de l'agent?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
