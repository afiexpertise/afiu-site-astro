# Résumé

Transformer une tâche ponctuelle en activité récurrente grâce à un contexte persistant, des Skills et des tâches planifiées.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Mistral Vibe
- **Ordre :** 5
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-230 — Adapter une requête à un contexte**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Créer un Project à la bonne granularité.
2. Formaliser des instructions et Skills réutilisables.
3. Identifier ce qui peut être planifié.
4. Définir des critères de validation.
5. Éviter la persistance d'informations devenues fausses.

# Agenda — théorie

- Project et contexte persistant.
- Skill réutilisable.
- Tâche planifiée et événement futur.
- Validation d'une exécution différée.
- Maintenance et obsolescence.

# Fil rouge — expérimentation personnelle

**État entrant :** La première tâche est résolue mais certaines étapes vont se répéter régulièrement.

1. Créer le Project associé au fil rouge.
2. Conserver uniquement les sources et instructions durables.
3. Formaliser une Skill pour une étape récurrente.
4. Planifier une action ou vérification pertinente.
5. Tester une nouvelle occurrence et valider ce qui a été réutilisé.

**État sortant :** La tâche ponctuelle devient une activité réutilisable sans supprimer les contrôles humains.

# Réflexion et questions de groupe

- **Qu'est-ce qui doit devenir permanent?**
- **Qu'est-ce qui ne doit surtout pas l'être?**
- **Quand une tâche planifiée doit-elle produire une notification plutôt qu'une action?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
