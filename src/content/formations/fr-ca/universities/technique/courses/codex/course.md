# Résumé

Transformer un besoin issu du fil rouge en tâche de développement exécutée et testée avec Codex.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** OpenAI ChatGPT / Codex
- **Ordre :** 8
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-450 — Utiliser le raisonnement guidé**
- **IA-460 — Utiliser les contraintes**
- **IA-510 — Collaborer avec l’IA**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Exprimer un besoin de développement à partir d'un objectif métier.
2. Faire inspecter une base de code avant changement.
3. Obtenir et valider un plan d'implémentation.
4. Faire modifier et tester le code.
5. Revoir le résultat et les risques.

# Agenda — théorie

- Besoin métier, spécification et critères de succès.

- Planification et découpage de la tâche.

- Revue, sécurité et responsabilité.

# Fil rouge — expérimentation personnelle

**État entrant :** Une étape répétitive du fil rouge justifie la création ou la modification d'un outil.

1. Décrire le besoin et les cas de réussite.
2. Faire inspecter le projet existant.
3. Demander un plan avant implémentation.
4. Faire réaliser une petite fonctionnalité et exécuter les tests.
5. Examiner les changements et corriger ce qui ne répond pas au besoin.

**État sortant :** Une fonctionnalité testée répond à un besoin concret de la tâche.

# Réflexion et questions de groupe

- **Jusqu'où peut-on déléguer le développement?**
- **Comment vérifier un changement que l'on n'aurait pas écrit soi-même?**
- **Quels tests sont indispensables?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
