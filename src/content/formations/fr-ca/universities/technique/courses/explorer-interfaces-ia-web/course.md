# Résumé

Gabarit commun du Module 3 pour apprendre une interface produit sans réinventer la pédagogie : conversation, paramètres, instructions, fichiers, sources, connexions et validation.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Tronc commun
- **Ordre :** 3 (gabarit commun)
- **Durée :** 210 minutes
- **Rôle :** Gabarit commun du Module 3, décliné pour Microsoft Copilot, Microsoft 365 Copilot, ChatGPT, Claude et Mistral Vibe.

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-230 — Adapter une requête à un contexte**
- **IA-240 — Identifier objectif, contexte, attentes et sources**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**
- **IA-610 — Protéger les données**
- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Se repérer dans une interface conversationnelle.
2. Distinguer conversation et recherche.
3. Configurer paramètres et instructions persistantes.
4. Ajouter fichiers et sources connectées en comprenant les permissions.
5. Réaliser le fil rouge de bout en bout dans l'interface étudiée.

# Agenda — théorie

- Lire l'interface : historique, conversation, zone de requête et fonctions disponibles.
- Paramètres, modèles ou modes et personnalisation.
- Instructions persistantes, texte, dictée et voix selon le produit.
- Fichiers, pièces jointes et sources connectées.
- Identité, authentification, autorisation, permissions et gouvernance.

# Fil rouge — expérimentation personnelle

**État entrant :** Les compétences conversationnelles sont acquises; le participant doit maintenant les transposer dans un produit réel.

1. Configurer l'interface et les préférences nécessaires.
2. Ouvrir une conversation dédiée au courriel du fil rouge.
3. Ajouter le courriel puis une pièce jointe.
4. Ajouter une source connectée lorsque le produit le permet.
5. Réaliser la tâche dans l'interface, vérifier les sources, valider le résultat et nettoyer les accès utilisés.

**État sortant :** Le participant sait utiliser le produit étudié comme espace de travail pour une tâche complète.

# Réflexion et questions de groupe

- **Qu'est-ce qui relève de la compétence conversationnelle et qu'est-ce qui relève du produit?**
- **Quelles permissions sont réellement nécessaires pour la tâche?**
- **Quels paramètres doivent être individuels et lesquels devraient être gouvernés par l'organisation?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
