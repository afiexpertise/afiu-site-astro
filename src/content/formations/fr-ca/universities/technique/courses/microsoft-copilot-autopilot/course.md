# Résumé

Comprendre et encadrer un travail persistant ou proactif qui continue au-delà d'une interaction ponctuelle.

Le cours s'inscrit dans le fil rouge du cursus : **une demande reçue par courriel ouvre une tâche que le collaborateur doit conduire de bout en bout avec l'aide de l'assistant IA**.

# Positionnement dans le cursus

- **Parcours :** Cursus IA orienté tâches
- **Produit :** Microsoft Copilot
- **Ordre :** 7
- **Durée :** 210 minutes

# Compétences couvertes

- **IA-130 — Comprendre le fonctionnement général d’un orchestrateur IA**
- **IA-320 — Évaluer la qualité d’une réponse**
- **IA-420 — Utiliser le Context Engineering**
- **IA-510 — Collaborer avec l’IA**
- **IA-530 — Utiliser l’IA dans les tâches quotidiennes**

- **IA-620 — Gérer les risques associés à l’IA**

# Objectifs pédagogiques

1. Distinguer travail ponctuel, persistant et automatisé.
2. Définir le contexte durable nécessaire.
3. Identifier déclencheurs et conditions d'arrêt.
4. Configurer les validations humaines.
5. Appliquer les principes de gouvernance.

# Agenda — théorie

- Travail ponctuel vs persistant.
- Contexte durable et état de la tâche.
- Déclencheurs, fréquence et conditions.
- Autonomie, supervision et escalade.
- Gouvernance et traçabilité.

# Fil rouge — expérimentation personnelle

**État entrant :** Certaines tâches similaires reviennent et nécessitent une préparation régulière.

1. Identifier une partie récurrente du fil rouge.
2. Définir ce qui doit être observé ou préparé de façon persistante.
3. Définir les conditions qui nécessitent une intervention humaine.
4. Tester un cycle complet avec validation.
5. Examiner ce qui est conservé entre deux occurrences.

**État sortant :** Le participant sait cadrer un travail persistant sans le confondre avec une automatisation non supervisée.

# Réflexion et questions de groupe

- **Quelle autonomie voulons-nous réellement accorder?**
- **Quelles informations peuvent rester persistantes?**
- **Qu'est-ce qui doit provoquer une interruption humaine?**

# Validation

Le participant doit pouvoir expliquer ce qu'il a confié à l'IA, identifier les sources utilisées, vérifier le résultat produit et déterminer si la tâche peut progresser vers l'étape suivante.
